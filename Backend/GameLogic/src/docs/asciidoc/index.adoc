= Game Logic API

This API follows the contract of the Prototipo 1 (sections 3.5, 3.8 and 4). It is only called by the Single Player component.

Game Logic is the only source of truth of each match: it stores the position, the moves and the result, and validates every move against the stored position. The client only sends the move in UCI notation.

The identifiers (the match id and the user id) are UUID v4 Strings. The dates are in ISO 8601 UTC. The colors are always "white" or "black".

== Errors

Every error has the same shape, with a machine-readable code and a human-readable message:

[source,json]
----
{ "error": { "code": "INVALID_MOVE", "message": "Jugada ilegal: e2e5" } }
----

[cols="2,1,3"]
|===
|Code |HTTP status |When

|VALIDATION_ERROR
|400
|Missing fields, fields with an invalid format, or a body that is not a valid JSON.

|GAME_NOT_FOUND
|404
|The match doesn't exist.

|INVALID_MOVE
|422
|The move is illegal in the current position, or is not written correctly.

|GAME_FINISHED
|422
|The match is already finished, so no more moves or resignations are accepted.
|===
